# BeatForge

A mod manager for **Beat Hazard 2**: install, turn on and off, and order mods, then play.

**Download:** from the BeatForge website, or the newest installer under [Releases](../../releases/latest).

- Windows, with Beat Hazard 2 on Steam.
- Unofficial.
- Windows SmartScreen may warn on first install (the installer isn't code-signed): choose **More info → Run anyway**.
- BeatForge updates itself; every update is signed and checked before it installs.

This repository holds releases only; the source isn't published here.
